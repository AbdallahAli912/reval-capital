# Reva Capital — Portfolio Landing Page

A responsive, Arabic-first portfolio built with semantic HTML, CSS, and vanilla JavaScript. The existing dark navy/gold visual direction has been retained while all Akam AlRajhi branding, projects, links, and stock imagery have been removed.

## Preview locally

Open `index.html` in a browser. The layout itself has no runtime dependencies; internet access is only used to load Google Fonts and to open external Facebook, WhatsApp, or telephone links.

## Accuracy notes

- No independently verifiable company website, email address, street address, or dedicated Reva Capital logo file was publicly available, so none was invented.
- The official page's current profile and project media use **Rivanew Development** branding; Royal Town media also shows **Namaa Developments**. The website preserves those visible labels and describes the items as opportunities published by Reva Capital rather than claiming Reva Capital owns or develops them.
- Time-sensitive prices, cash discounts, availability, and conflicting construction percentages shown in promotional graphics were intentionally omitted. Visitors are directed to the official channels for current information.
- The former D.O.S.E, Scenario, and Scene 7 content belonged to the previous incorrect company identity and has been removed.
